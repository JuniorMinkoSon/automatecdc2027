Comment préparer un modèle

Partez d'un document que vous avez déjà déposé par le passé. Remplacez les informations qui changent d'un marché à l'autre par un champ entre doubles accolades, par exemple {{ENTREPRISE_RAISON_SOCIALE}} ou {{AO_NUMERO}}.

Pour un tableau qui se répète, mettez {{#LISTE:personnel}} dans la première cellule de la ligne à répéter, puis les champs de chaque élément : {{nom}}, {{poste}}.

L'application lit les champs du document au moment du dépôt : vous n'avez rien à déclarer ailleurs. Un document illisible est refusé tout de suite, et non le jour où vous générez un dossier sous échéance.

Reprenez le code d'un modèle livré pour le remplacer par le vôtre, sans en priver les autres entreprises.
